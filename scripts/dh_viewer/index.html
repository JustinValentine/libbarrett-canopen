How to check the geometry
  1. Set the joint angles to a known pose.
  2. Select and sweep one joint. Compare its orange rotation axis with the physical joint.
  3. Edit α, a and d to place the next frame correctly.
  4. Check the wrist at several angles, then the tool origin and orientation.

Links show the DH offsets, not the physical robot’s shape. A visual match alone does not calibrate the robot.
